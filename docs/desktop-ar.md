# برنامج سطح المكتب «AFMI Projets»

برنامج يُثبَّت على الحاسوب ويفتح المنصة في نافذته الخاصة، بأيقونته وقائمته، دون متصفح.

## كيف يعمل

المنصة جماعية: كل الفريق يعمل على البيانات نفسها في الوقت نفسه. لذلك تبقى البيانات على الخادم المشترك (Supabase + Netlify، انظر [دليل النشر](deploy-ar.md))، والبرنامج يتصل به. **يحتاج البرنامج إلى الإنترنت**، وإن انقطع يعرض رسالة مع زر «إعادة المحاولة».

- يتذكر عنوان المنصة وجلسة الدخول وحجم النافذة.
- الدخول برمز من 6 أرقام يصل بالبريد، يُكتب داخل البرنامج.
- الروابط الخارجية (المرفقات، البريد…) تُفتح في المتصفح، وتنزيل ملفات Excel وطباعة التقارير يعملان من داخل البرنامج.
- القائمة: تغيير عنوان المنصة، اللغة (العربية/الفرنسية)، التكبير والتصغير.

## التثبيت على Windows

1. شغّل `AFMI-Projets-Setup-1.0.0.exe`.
2. قد يظهر تحذير أزرق «Windows protected your PC» لأن البرنامج غير موقَّع بشهادة مدفوعة: اضغط **More info** ثم **Run anyway**.
3. اختر مكان التثبيت ثم **Install**. تظهر أيقونة «AFMI Projets» على سطح المكتب وفي قائمة ابدأ.
4. عند أول تشغيل: اكتب عنوان المنصة (مثلاً `https://afmi-projets.netlify.app`) ثم **متابعة**.
5. اكتب بريدك ← يصلك رمز من 6 أرقام ← اكتبه ← **دخول**.

**الإزالة**: الإعدادات ← التطبيقات ← AFMI Projets ← إلغاء التثبيت.

## بناء نسخ جديدة (Windows وMac وLinux) مجاناً

في GitHub ← **Actions** ← **Desktop app** ← **Run workflow**. يمكن كتابة عنوان المنصة في الخانة ليفتحها البرنامج مباشرة دون سؤال. بعد نحو 10 دقائق تجد الملفات في أسفل صفحة التشغيل:
- Windows: `AFMI-Projets-Setup-….exe`
- Mac: `AFMI-Projets-….dmg` (أول فتح: انقر بالزر الأيمن ← **Open**، لأنه غير موقَّع)
- Linux: `AFMI-Projets-….AppImage`

## للمطورين

```bash
cd desktop && npm install && npm start
```

اختبار آلي للبرنامج (يحتاج المنصة تعمل محلياً على المنفذ 3000):

```bash
xvfb-run -a npx playwright test -c desktop/test/playwright.config.ts
```
